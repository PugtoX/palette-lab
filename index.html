Palette Candidates

Purpose: render one identical component skeleton in several colour schemes so they can be compared side by side. The text in every preview is generic placeholder copy. It deliberately contains no real names, brands or prices — so there is nothing to scrub when you reuse this file, and because the content is identical you end up comparing the colours themselves.

Choose between the candidates marked Shortlisted. The others are kept for comparison only.

Variables: --page page · --panel card surface · --panel-hover hover surface · --line / --line-strong rules · --fg body text · --muted secondary text · --accent accent · --accent-soft accent wash · --grid background grid.

a / b / c each define two modes (light + dark); d / e / f define only one mode each (light or dark). Both shapes can coexist — if a project has no theme toggle, the second shape is less work.

A Technical Blue low-risk refinement

Same structure, contrast fixed. Calm and conventional — the lowest-risk option, and the hardest to get wrong. Nothing about the character changes, only how legible it is on a bright screen.

B Editorial Mono black-and-white editorial

Colour steps aside so imagery and content lead. Watch the buttons — they carry impact through size and weight rather than hue, inverting between light and dark. Risk: accent-coloured links lose their colour cue and have to lean on weight alone.

Aa Type scale independent of colour · shared by every candidate

The other half of a design system. The type scale is independent of colour, so you set it once and every candidate reuses it. 16px is the body baseline: up to 20 / 28 / 40, down to 14 / 12 — six steps (steps of roughly 1.25–1.43, not a strict geometric series). On mobile the hero headline drops from 40px to 32px so a long headline does not wrap too many times.

40px · 1.05 Headline here Hero headline h1 (32px on mobile)
28px · 1.15 Section title Section title h2
20px · 1.3 Item heading Sub-heading h3
16px · 1.6 Body copy sits at this size. Body baseline
14px · 1.6 Secondary line of text. Secondary text
12px · 1.5 LABEL · 000 / 000 Labels and values (monospace figures)

D Studio White clean clinical · light Shortlisted

Light base + deep teal. Clean, credible, unhurried — like a good physiotherapy studio. Deliberately avoids the red-and-black some industries default to. A light base is easiest on the eye indoors.

E Ember after-hours · dark Shortlisted

Near-black base + warm amber. Dark is everywhere, and done well it looks expensive, done badly it looks like a template — the difference is restraint: one bright accent, everything else pushed down. It looks especially good on OLED phones. The cost is legibility outdoors in bright sun.

F Concrete local editorial · light Shortlisted

Warm grey base + brick red. The most "local / street" of the three, and the least like an industry template. Brick red is more restrained than pure red — it does not shout. A good backdrop once photos arrive.
